BoardAF
Backend Project · Group 3

Play more.
Own less.

Discover, reserve, and rent board games without having to buy them. BoardAF makes board game rentals simple for players and rental shop owners.

What is BoardAF?

BoardAF is a board game rental management system designed for small rental businesses. It helps customers find available games, make reservations, and rent games for a selected period of time.

For business owners, BoardAF simplifies game inventory management, rental tracking, and return monitoring.

Core Features

Game Catalog

Browse board games and check their current availability.

Reservations

Reserve and rent games for a selected period.

Rental Management

Track active rentals, returns, and rental history.

Who is it for?

Meet Michael – the owner of a small board game rental shop.

He wants an easy way to manage his game collection, track rentals, and avoid double bookings.

BoardAF also helps customers enjoy different board games without purchasing every title.
